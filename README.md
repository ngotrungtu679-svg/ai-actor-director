# AI 演员导演（ai-actor-director）

**教 AI 视频模型「演戏」的 Agent Skill：把面瘫的角色，变成脸上有层次、眼里有戏的角色。**

你负责剧情和台词，它负责表演。给它一段剧情、台词、分镜，甚至一条已经生成好的视频，它会像表演指导一样，把内容改写成可灵、Seedance、Wan 等视频模型真正「演得出来」的表演提示词。

## 解决什么问题

用 AI 生成剧情视频时，你一定遇到过这些情况：

- 角色全程面瘫，像个精致的假人
- 哭戏只会硬挤眼泪，没有情绪铺垫
- 眼神空洞，从头到尾一个样
- 双人戏各演各的，毫无交流感
- 单一情绪到底，表演没有层次

这些不是模型不行，而是提示词里只写了「他很伤心」，没告诉模型**怎么演**。这个 Skill 把一套表演方法论沉淀成提示词工程规则，让你的 Agent 自动完成「讲戏」这一步。

## 核心方法：三层表演结构

每个镜头的提示词都围绕三个问题重写：

1. **面对对方的目的** —— 人物此刻想让对方感到什么、相信什么、做什么？
2. **情绪转变** —— 情绪从哪里来，最后变成了什么？（如：从心碎转成温柔）
3. **表情动线** —— 情绪如何落到脸上：原有表情 → 被击中的第一处变化 → 扩大或被控制 → 结尾停在脸上的状态

不是堆形容词，而是让模型理解「人物正在对对方做什么」，表演自然就有了方向。

## 它能做什么

- **表演提示词增强**：输入剧情、台词或分镜，输出可直接喂给视频模型的动作链条式提示词
- **已有视频诊断**：输入生成好的视频，输出六维度诊断报告（目的 / 转变 / 动线 / 动作道具 / 口型台词 / 生成伪影），再给出逐条对应问题编号的修正 prompt
- **导演讲戏本集成模式**：拿到完整讲戏本后逐镜头增强，批量产出每镜表演提示词，可直接接入多 Agent 短剧制作流水线
- **内置 8 份表演参考库**：情绪知识、面部与近景、眼神与关系感、台词与声音、身体与道具、镜头与时间、提示词质量控制、寻找变化的方法，按需读取，不注水

## 效果示例

输入（一段导演讲戏本）：

> 近景，年轻人低头看到碗里多出来的蛋。他的筷子停了一下，视线慢慢从碗里抬起来，看向对面。大爷已经转过身去擦柜台了。年轻人嘴唇动了一下，但没说出什么。

经过本 Skill 增强后的视频提示词：

> 近景，便利店关东煮柜台，冷白荧光灯下。年轻人低着头，目光散在碗里——发现多出来的那颗蛋时，筷子停住，原本涣散的目光突然有了焦点。他盯着蛋看了一秒，下眼睑微微收紧，嘴角有一个极轻的颤动随即被压回去。视线缓缓抬起越过柜台，大爷已经背对着他在擦台面。年轻人的嘴唇张开又合上，喉结轻滚一次，眼眶里泛起薄薄一层湿润但没有落泪。最后视线停在大爷安静的背影上，脸上疲惫仍在，但多了一层被温暖击中后说不出口的感激。

同样是 10 秒近景，前者模型只会演「抬头看一眼」，后者演的是「被陌生人的温柔击中」。

适用于 Claude Code、QoderWork 及任何支持 Agent Skill（SKILL.md）格式的环境：

```bash
# Claude Code
git clone https://github.com/ngotrungtu679-svg/ai-actor-director.git ~/.claude/skills/ai-actor-director

# QoderWork
git clone https://github.com/ngotrungtu679-svg/ai-actor-director.git ~/.qoderwork/skills/ai-actor-director
```

也可以直接下载本仓库 zip，解压到对应产品的 skills 目录。

## 使用

安装后用自然语言对 Agent 说：

- 「帮我改一下这条 prompt，角色演得太僵了」
- 「写一个克制的哭戏镜头提示词」
- 「帮我诊断这条视频，哪里演得不对」
- 「为这份讲戏本逐镜增强表演提示词」
