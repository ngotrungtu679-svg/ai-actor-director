# AI角色演技优化（ai-actor-director）

> **一个专门提升 AI 视频「演技」的 Agent Skill：把剧情、台词、分镜改写成可灵（Kling）、Seedance、Wan 等视频模型真正演得出来的表演提示词。角色不再面瘫，哭戏不再假，眼神不再空洞。**

你负责剧情和台词，它负责演技。

用 AI 做剧情视频，最难的不是画面多精致，而是**角色演得像不像**——观众一眼就能看出「假」：脸上的表情和剧情对不上，哭戏没有铺垫，两个人同框却像各演各的。这个 Skill 把一套系统的表演方法论沉淀成提示词工程规则，让你的 Agent 在生成视频前自动完成「讲戏」这一步，把「他很伤心」这种无效描述，改写成模型能照着演出来的演技指令。

## 它解决什么演技问题

用 AI 生成剧情视频时，你一定遇到过这些情况：

- **角色面瘫**：全程一个表情，像个精致的假人，情绪完全不上脸
- **表情僵硬**：有表情但很假，像贴上去的，看不出情绪是怎么来的
- **哭戏不真实**：只会硬挤眼泪，没有哽咽、压抑、失控的过程，观众不感动
- **眼神空洞**：从头到尾眼神一个样，没有焦点、没有躲闪、没有看向对方时的情绪
- **双人戏没交流**：两个角色各演各的，没有对视、反应和拉扯，不像在对话
- **表演没层次**：单一情绪到底，没有转变，没有克制与爆发的对比

这些问题的根源不是模型不行，而是提示词只写了「他很伤心」，没告诉模型**怎么演**。演技是落在脸上的物理过程：情绪从哪来、在哪一刻被击中、怎么扩大或被压下去、最后停在哪里。这个 Skill 就是把这套「讲戏」方法教给你的 Agent。

## 核心演技方法论：三层表演结构

每个镜头的提示词，都围绕三个表演问题重写：

1. **面对对方的目的** —— 人物此刻想让对方感到什么、相信什么、做什么？这是表演的发动机。比如「想让对方相信自己没事」「想让对方主动开口挽留」——有了目的，演员才知道用什么方式面对对手。
2. **情绪转变** —— 情绪从哪里来，最后变成了什么？好的表演永远是一条弧线，不是一个点。用「从 X 转成 Y」表达：从心碎转成温柔、从愧疚转成承担、从羞耻转成体面。
3. **表情动线** —— 情绪如何落到脸上，按顺序写清：原有表情 → 刺激落在脸上的第一处变化 → 情绪扩大或被控制 → 结尾停在脸上的状态。两到三个可见变化（眼睑、泪光、嘴角、视线），共同完成同一条转变，而不是把整张脸的每块肌肉都指挥一遍。

不是堆形容词，而是让模型理解「人物正在对对方做什么」，表演自然有了方向和层次。

## 它能做什么

- **演技提示词增强**：输入剧情、台词或分镜，输出可直接喂给视频模型的动作链条式表演提示词，适配可灵、Seedance、Wan 等主流模型
- **已有视频演技诊断**：输入一条生成好的视频，输出六维度诊断报告（目的 / 情绪转变 / 表情动线 / 动作道具 / 口型台词 / 生成伪影），每条标注现象、维度和对观众的影响，再给出逐条对应问题编号的修正 prompt
- **导演讲戏本集成模式**：拿到完整讲戏本（P01、P02…）后逐镜头增强，批量产出每镜的表演提示词，可直接接入多 Agent 短剧制作流水线
- **内置 8 份表演参考库**：情绪知识、面部与近景、眼神与关系感、台词与声音、身体与道具、镜头与时间、提示词质量控制、寻找变化的方法。Agent 按需读取，不注水，保证每条 prompt 都用对方法

## 效果示例

输入（一段导演讲戏本）：

> 近景，年轻人低头看到碗里多出来的蛋。他的筷子停了一下，视线慢慢从碗里抬起来，看向对面。大爷已经转过身去擦柜台了。年轻人嘴唇动了一下，但没说出什么。

经过本 Skill 增强后的视频提示词：

> 近景，便利店关东煮柜台，冷白荧光灯下。年轻人低着头，目光散在碗里——发现多出来的那颗蛋时，筷子停住，原本涣散的目光突然有了焦点。他盯着蛋看了一秒，下眼睑微微收紧，嘴角有一个极轻的颤动随即被压回去。视线缓缓抬起越过柜台，大爷已经背对着他在擦台面。年轻人的嘴唇张开又合上，喉结轻滚一次，眼眶里泛起薄薄一层湿润但没有落泪。最后视线停在大爷安静的背影上，脸上疲惫仍在，但多了一层被温暖击中后说不出口的感激。

同样是 10 秒近景，前者模型只会演「抬头看一眼」，后者演的是「被陌生人的温柔击中」——这就是有演技和没演技的区别。

## 使用

安装后，用自然语言对 Agent 说：

- 「帮我改一下这条 prompt，角色演得太僵了」
- 「写一个克制的哭戏镜头提示词」
- 「帮我诊断这条视频，哪里演得不对」
- 「为这份讲戏本逐镜增强表演提示词」
