# 把提示词写得比原句更有用

输出只是扩写原句、面部细节不足、动作太多或读起来生硬时读取。

## 先检查有没有新的表演方向

把新 prompt 缩成一句话，与用户原句比较。

原句：

```text
父亲想起亡妻，非常悲伤，却强忍眼泪安慰儿子。
```

没有改善：

```text
父亲笑容僵住，眼眶泛红，悲伤涌上来，但继续微笑安慰儿子。
```

真正改善：

```text
父亲先和儿子一起承认这份思念，再把思念转成欣慰，像在替缺席的母亲见证儿子的幸福。
```

只有第三种会让演员改变演法。先得到它，再设计表情。

## 内容优先级

按这个顺序保留：

1. 人物想对对方做什么；
2. 情绪从什么转成什么；
3. 什么事件触发变化；
4. 表情动线的起点和终点；
5. 两到三个共同完成这条动线的面部信息；
6. 剧情必需的声音或关键行动；
7. 镜头和一项写实细节。

后面的内容不能挤掉前面的内容。

## 面部细节既不能太少，也不能散

只有“眼眶泛红”通常不够。近景至少让观众知道：

- 原来的表情发生了什么；
- 眼神或泪水怎样变化；
- 最后的脸与开始有什么不同。

例如：

```text
原本温和的笑停在嘴角，视线仍留在儿子脸上；泪光聚起但没有落下。重新笑起来时，眼眶仍湿，眼神已经变成欣慰。
```

这些细节属于同一条变化。若只是依次罗列眉毛、眼睑、鼻翼、嘴唇、下颌和呼吸，仍然是清单。

## 删除不承载表演的动作

身体动作只保留剧情结果或关系变化，例如离开、拒绝、拥抱或交出遗物。为了显得细腻而加入的停手、低头、抬眼、整理衣服、摸杯子或掖被角，不能代替面对对方的目的和面部表演。

同一动作只说一次。连续出现“缓缓、轻轻、微微、短暂”时，保留真正改变节奏的一个。

## 翻译成片场语言

分析语言：

```text
角色在共同丧失被提及时完成由情感抑制向代偿性见证的策略转化。
```

片场语言：

```text
他不急着把悲伤藏掉，先和儿子一起承认对母亲的想念，再把这份想念变成真心的欣慰，像在替她看着儿子走到今天。
```

最终 prompt 应该让演员一遍就知道自己如何面对对方，同时让视频模型知道这次变化如何出现在脸上。

## 最后检查

- 演员会不会因为这条 prompt 采用不同的表演策略？
- 是否有一个有剧情根据的面对对方的目的？
- 情绪是否有明确的起点和结尾变化？
- 面部是否有起点、被击中的瞬间和结尾状态？
- 两到三个细节是否服务同一条变化？
- 是否删除了不推进剧情的身体小动作？

如果新 prompt 只是更长，不算完成。
