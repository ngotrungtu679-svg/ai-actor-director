# 目光、倾听与人物关系

在双人戏缺少交流、眼神漂移、全程盯人或多人同时演满时读取。

## 目光先完成面对对方的目的

先判断人物看对方是为了什么：请求被认出、让对方安心、等待原谅、逼对方承认、允许对方看见自己的悲伤，还是替缺席的人见证这一刻。

目光可以直接成为表演结果，不必每次都再接一个身体动作：

```text
她认出母亲眼里的陌生后，脸上的期待消失；视线仍留在母亲脸上，从“要求对方认出自己”转成“先让她感到安全”。
```

这比“先看手、再看门、然后低头、最后抬眼”更集中。

## 对视要有节奏

角色可以在说关键台词时看对方，在等待回应时保留视线，在无法承受结果时避开。只写与情绪和关系有关的一次变化，其余让模型自然完成。

写清：

```text
看谁或避开谁 + 为什么 + 目光里发生了什么变化
```

例如：

```text
他一直看着母亲，想把坏消息说出口；愧疚涌上来后，声音卡住，直到她低头看见手表才移开目光。
```

## 双人戏只详细写一个人

选择受到触动最大的人。另一人负责说出台词、做出拒绝、离开或接受等必要事件，不再为两个人分别安排完整的脸、手、呼吸和身体变化。

对方的反应只有在它进一步改变主要人物时才写。例如，父亲允许儿子看见自己也在思念母亲；儿子没有躲开后，他才把这份共同的思念转成欣慰。

## 多人戏安排注意力先后

多人戏只标出消息从谁传到谁，以及观众最后该看谁。背景人物继续原有状态，不要求所有人同时转头、停手和变脸。

靠近、退开、让路或挡住出口属于关键关系动作，只有它确实改变局面时才写。
