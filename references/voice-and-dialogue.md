# 台词、声音与倾听

在台词像背诵、听者像木偶、停顿没有原因或每句声音都一样时读取。需要控制台词时长、对口型或配合外部音频时，读取“口型同步”一节。

## 台词先作用于对方

写台词前先回答：角色想用这句话让谁做什么？

可能是让对方确认、安心、停下、解释、表态、让步、继续说或闭嘴。选择最符合剧情的一项，再决定怎么说。

例子：

- “没事”可以用来安慰对方，也可以用来结束追问；
- “你走吧”可以是赶走、试探挽留，也可以是给对方一个出口；
- “我知道了”可以是接受结果，也可以是停止继续暴露自己。

不要把台词文字改掉。通过说话对象、停顿、重音和句尾表现不同目的。

## 先听见，再回应

找出对方哪一个词、语气或动作改变了角色。回应从这个地方开始。

```text
对方说出名字 → 他原本准备好的回答停住 → 改用更正式的称呼继续追问
```

只在新信息真正改变了角色时，才让起句、速度、音量或手上任务发生变化。

## 一次只改一个声音重点

从下面选最有用的一项：

- 开口变早、变晚或被打断；
- 某个新信息被说得更清楚；
- 句子变短、变慢、变快或中途改口；
- 音量因为距离、公开场合或遮掩而改变；
- 句尾交给对方、吞回去、停在半句或不给回应余地。

其余声音保持自然。身份、职业和情绪词本身不决定固定声线。

## 倾听也会改变说话者

主要听者只需要一个与内容有关的回应，例如：

- 看向刚被提到的证据；
- 停下手里的任务；
- 没有接话；
- 追问一个词；
- 给对方继续说的空白。

说话者看到这个回应后，下一句要有所变化。背景人物继续自己的任务，不复制主要听者。

## 沉默和改口

沉默要有对象和结果：等对方解释、拒绝回答、确认事实、给对方空间、惩罚对方或尚未决定。

改口时保留被吞回去的痕迹：原本要说什么、在哪个词前停下、换成了什么更安全或更有用的话。只写剧情能支持的部分。

## 口型同步

视频模型对口型能力有限。台词需要被观众听清、对上嘴型时，遵守以下规则。

### 台词长度与秒数匹配

- 中文正常语速约每秒 3—5 个字：4—6 秒镜头台词控制在 15—25 字，7—12 秒镜头不超过 50 字；
- 写进 prompt 的台词必须是完整句子。不用省略号拖尾、破折号中断或“等等”“之类”代替没写完的话——模型会为这些符号硬对口型；
- 台词超长时优先删减字数，不靠“语速变快”硬塞；语速提示只用于情绪，不用于救场。

### 对口型 prompt 写法

- 说台词的人必须在画面中清晰可见，且每段台词只归属一个人；多人同时说话、画外音最容易口型崩坏；
- 台词用引号完整标出；情绪、停顿、重音等节奏提示写在引号之外，不插进台词中间；
- 一个镜头尽量只安排一人一段台词；必须有对话来回时，拆成多镜头，或只保证主要人物的口型；
- 使用外部音频（音频直通、后期配音）时，prompt 中保留与音频一致的台词原文，只补情绪、表情动线和说话对象，不改写台词文字；
- 沉默、改口、被打断本身不额外占口型时长，但要在 prompt 中写清发生在台词之前还是之后，避免模型给沉默配嘴部动作。

## 示例

```text
她问“你早就知道？”他原本要解释，听见“早就”两个字后停住，改成一句很短的“不是你想的那样”；
重音落在“你”，句尾没有继续辩解，只等她是否还愿意听。
```
