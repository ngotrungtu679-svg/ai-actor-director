# 设计表情动线

中近景、近景、特写、哭戏或微表情任务读取本文件。爆发、喜剧、无台词等非克制戏路需要示例结构时，读取文末“常用示例”。

## 先确定脸上的起点和终点

表情是一段变化过程。先写清：

```text
开始时脸上是什么状态 → 哪一刻被击中 → 哪部分先暴露情绪 → 人物怎样处理它 → 最后留下什么
```

例如父亲听见儿子提到亡母：

```text
温和的笑 → 听见“妈” → 笑先停在嘴角，眼里出现思念 → 泪光聚起但不落 → 重新笑起来，湿润的眼神变成欣慰
```

这条动线比单独写“父亲悲伤、眼眶泛红”更清楚。

## 从四组信息中选择两到三个

### 原有表情

先让观众知道变化发生在什么基础上：

- 温和的笑停住、退去或重新出现；
- 礼貌和平静开始维持不住；
- 原本紧绷的防备突然松开；
- 一片空白之后才出现痛苦。

### 目光

目光必须有对象和关系意义：

- 仍看着对方，允许对方看见自己的情绪；
- 视线停在对方脸上，却失去原来的笃定；
- 终于无法继续面对，短暂避开；
- 从等待确认，变成安抚、告别或重新审视。

普通近景优先写目光对象和变化。瞳孔收缩、焦点细移只适合稳定极近特写，并且确实能被画面看见时使用。

### 眼周与泪水

哭戏必须选定阶段，不把所有阶段都塞进五秒：

- 下眼睑开始收紧，泪光刚出现；
- 泪水在眼眶里聚起，但没有落下；
- 第一滴泪越过下眼睑；
- 已经哭过，眼眶仍湿，正在恢复；
- 彻底失控，无法继续维持表情。

需要更写实时，可以增加眼周或鼻翼自然泛红、泪膜反光、泪水表面张力中的一项。它们只增强当前哭戏阶段。

### 嘴与下颌

嘴部适合表现正在说、忍住或重新组织情绪：

- 笑停在嘴角，随后完全退去；
- 原本要说话的嘴唇停住，开口时声音已经变了；
- 嘴唇短暂压紧，用来阻止一句话或一次失控；
- 下颌收紧后重新松开，让人物能够继续面对对方；
- 重新出现的笑与湿润的眼睛形成两层情绪。

说话造成的正常嘴部运动不算额外表演。

## 细节必须组成同一条变化

合适：

```text
原本温和的笑停在嘴角，视线仍留在儿子脸上；下眼睑微微收紧，泪光聚起却没有落下。片刻后他重新笑起来，眼眶仍湿，眼神已经从思念变成欣慰。
```

这里的嘴角、视线、下眼睑和泪光都在完成“思念转成欣慰”。

不需要把眉毛、上下眼睑、鼻翼、嘴角、下颌、喉结、呼吸和手指全部写一遍。每增加一个细节，都要能回答：它让观众看见了这条变化的哪一步？

## 根据景别控制精度

- 中景：写整体表情、目光对象和是否落泪；
- 中近景：写表情起落，加眼周或嘴部中的一项；
- 近景：写完整表情动线，选择两到三个细节；
- 极近特写：可以增加泪膜、眼周泛红、唇纹或皮肤张力中的一项。

镜头看不见的细节不写。景别越远，越应该让完整表情和面对对方的目的承担表演。

## 常用示例

### 克制型：失忆母女

```text
母亲问“你是谁？”后，女儿脸上的期待一下消失，视线仍留在母亲脸上；下眼睑收紧，泪光慢慢聚起。她放下“让母亲认出自己”的期待，重新露出一个像初次见面般温柔的笑，眼眶里的心碎仍没有完全退去。
```

### 克制型：婚礼父子

```text
儿子提到母亲时，父亲的笑停在嘴角，视线没有躲开；泪光聚起却不落。随后他重新笑起来，眼眶仍湿，笑里已经从思念转成替儿子高兴的欣慰。
```

### 克制型：离婚戏（多阶段哭戏 + 景深双人构图）

面对对方的目的：主动结束关系的人，在对方真的离开后被自己的决定击中。景深构图服务双人戏：前景虚化男人的肩膀和侧脸，后景聚焦女人面部特写，皮肤纹理清晰。哭戏分三阶段（平静→泪光聚起→无声落泪），每个阶段各占一段时长。

```text
固定机位长镜头，景深构图。女人平静地说：“离婚吧。”男人沉默片刻，起身从她身侧走过，离开画面。女人目送他离去，原本平静的表情开始颤动；下眼睑收紧，泪光在眼底聚起，嘴唇紧抿。几秒后她终于撑不住，低下头，双手撑住桌沿，无声落泪，肩膀颤抖，泪水滑过脸颊。
```

### 外放爆发型：当众反击

爆发戏同样是一条弧线，有起有落。愤怒的可见重心在眼神压迫、下颌收紧、语速停顿和身体前倾，爆发之后必须落到一个新的关系位置：

```text
主管把方案摔回桌上时，她先盯住对方两秒没有说话，下颌绷紧；随后声音陡然拔高，把压着的话一次性倒出来，眼睛瞪圆，身体前倾越过办公桌，手指点着方案。说到最后一句，声音反而沉下来，胸口起伏，眼神没有退让——愤怒已经转成“大不了不干了”的决绝。
```

注意爆发前有停顿、爆发后有余波，中间只选一条最狠的升级线。不要从第一帧吼到最后一帧，观众会失去参照。

### 喜剧反应型：开会憋笑

喜剧的核心是时间差和泄露：反应慢半拍、理智追不上身体、想藏的地方正好藏不住。喜剧憋笑与苦情忍泪不同，重点是“没藏住”被观众看见：

```text
听见同事一本正经念出自己昨晚写的尴尬文案，她先配合地点头，两秒后才反应过来，眼睛猛地睁大，嘴角控制不住地往上抽。她立刻低头假装记笔记，肩膀抖了两下；再抬头时拼命板住脸，眼底全是没来得及收走的笑意。
```

### 无台词纯表演型：电梯里的职业微笑

没有台词时，表情动线自己承担全部变化，用环境动作做节拍器（电梯门、广播、镜面），不补写台词也不加内心独白字幕：

```text
无台词，近景。她独自站在电梯里，先对着反光的轿厢门练习了一遍微笑；电梯下行的几秒里，笑一点点撑不住、退去，只剩疲惫。楼层到达的提示音响起，她吸了口气，重新把笑挂回脸上，抬眼走出去。
```

示例提供结构，不要求每场戏都使用笑、下眼睑或泪光。根据人物面对对方的目的重新选择。
